PARA SUBIR A GITHUB PAGES
1. Sube index.html y la carpeta img al repositorio.
2. Si quieres música, coloca musica.mp3 junto a index.html.
3. En GitHub: Settings > Pages > Deploy from branch > main > / (root) > Save.
4. Espera unos minutos y abre la dirección que GitHub te muestre.

IMPORTANTE:
Los SVG incluidos son dibujos decorativos originales para que la página funcione sin depender de imágenes externas. Si quieres usar imágenes concretas de Kuromi, Hello Kitty o Snoopy, reemplaza los tres archivos de img manteniendo exactamente sus nombres.
